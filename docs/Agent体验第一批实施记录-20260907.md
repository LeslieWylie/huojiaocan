# Agent体验第一批实施记录

## 已实施
- 复用Pi，保留搜索2次、原页阅读2次/4页尝试、生成最多3轮及共享截止时间。
- 额外限制检索模型最多4轮，防止无效参数响应在原有截止时间内持续空转。
- 检索停止摘要区分时间、预算、工具、模型、访问拒绝和依据不足；只包含受控枚举与计数。
- 原文/引文主语等问题先尝试读取服务器目录授权的原页。仅有摘要时拦截确定性回答，READY不是完成证明。
- 最后审校失败或被跳过时，不再因前两轮成功就标记完成；保留有效回答，提示未完成。
- 访问拒绝不继续确定性补搜其他来源。
- 前端等待显示本轮问题；请求发送前同步设置重复提交保护。
- 单标签页按账号和草稿记录进行中的问题，刷新后只恢复文字并提示无法接回执行，不自动重发。
- 已提交结果因依据不足被阻止时，不用空答案覆盖原有草稿。
- 旧响应无记录时不补造执行步骤，已有保存失败仅重试保存逻辑保留。

## 边界
sessionStorage只记录本标签页的待确认请求，不是后台任务或服务端checkpoint。
执行中刷新不承诺恢复同一模型请求；不能保证外部调用exactly-once。
本批没有增加审校回跳检索、运行表、公共接口、队列、取消或连接切换。
原页已读取仅证明材料获取，不等于句意正确或教师审核通过。

## 接口说明

- review：status、stopReason、roundsAttempted/Completed计数。
这些计数是编排层逻辑次数，不是供应商账单或底层网络重试次数。

# 2026-09-07：原页阅读、纠错编排与板书锁定

## 本轮针对的真实问题

上一轮付费测试发现：引文对象混淆、纠错后课时定位仍冲突、板书按序号机械分组、原生锁定确认无法可靠自动操作。本轮只围绕这些问题与教材阅读链路整改，不增加新的教师入口。

## 已实现

- 复用 Pi Agent：目录候选 → 临时章节句柄 → 原页及同节相邻页 → 必要时补搜 → 生成与修订。模型不提交文档ID或物理页；引用仍由服务端绑定。
- 读取只使用当前授权范围和固定篇目，目录无明确范围或身份冲突时不猜测。单次读两页、最多四页，私有材料不使用公开快照兜底。
- 最多两次补搜、两次原页阅读、四次工具执行；检索共享最多30秒，单个目录/原页请求最多4秒，生成遵守原请求截止时间，不因超时重新获得整段预算。
- 新整页替换同页摘要，后续命中的关键页不再被旧结果挤出；给各材料类型预留上下文位置。
- 初稿、核对、定向修订最多三轮。拒绝较差候选时仍保留审校发现，第三轮失败或无时间时不丢弃待确认问题。
- 模型核对提示要求检查引文对象、段落与转折关系，并同步修改问题理解、回复、摘要、课时、活动及三卡。新增课时冲突与核对引用的确定性检查；这不等于自动证明教材解释正确。
- 板书优先沿用真实分组；没有可靠类别则显示落笔顺序。结论必须显式存在，不把最后一项擅自提升为结论。显示层不覆盖教师修改或引用身份。
- 锁定改为站内对话框：取消不写入、确认防重入、失败保留修改、锁定后保留复制版本入口。

### 测试中发现并补修

1. 新课仅改URL未重挂载，旧draftId导致输入区永久禁用：改为多页导航，加入回归用例。
2. 模型结构化输出截断/格式无效：在原截止时间和最多两次传输尝试内修复一次，给教案与三卡独立输出预算。只记录输出长度、结束原因等形状信息，不记录原文或凭据。
3. BFF未透出未解决的教学问题：保留并展示待教师核对，不再默认宣称教材审校全部完成。课时定位冲突时用中性提示替换错误定位。
4. 方案和三卡一轮同时输出负担过重：问答只生成方案，教师确认后单独生成卡片。
5. 整页读取后的展示片段取页首，可能出现无关诗歌：改为从真实原页选择与本轮问题相关的连续片段；不改变原页正文或引用身份。旧草稿不自动重写历史摘要。
6. 纠错只写reply而遗漏结构字段：完整方案修订明确要求目标、重点、流程、问题链、评价；即使通用结构兜底补齐，原始遗漏仍作为待核对问题保留，不能被“字段齐全”掩盖。
7. 真实评价卡把概括语“以物喜，以己悲”写成课文原句：对明确要求摘录原句的评价任务，比对预期回应中的引号文本与当前学生教材片段；未匹配进入定向修订，或要求改成概括任务。此规则是有限范围警告，不是对全部教材事实的证明。
8. 新三卡截图发现服务端仍生成另一组名称的轮转分组：补齐识别两种历史默认结构，服务端和前端新建板书均改为按落笔顺序分组；保留手改文字、可靠的已有分组和引用，双列居中。
9. 只有两源材料时仍显示“三类材料综合”：改为“基于材料综合”，不虚报课标覆盖。

### 调用与限制

- 截至三卡首次生成：4次问答提交（2次结构化响应失败、2次成功）和1次三卡生成成功。一次操作可能含多次模型/工具调用；没有读取账单，不报告虚构费用或确切底层调用次数。
- 已生成卡片仍需教师逐条核验：提问中的个人境遇与景物关系、评价的原句/概括区分都不能靠有页码就认定正确。
- 旧测试草稿的完整教案仍有通用兜底内容。新增规则使这种遗漏可见并进入后续修订，不宣称已经自动修好所有历史方案。
- 自部署索引底层仍保留词面召回；本轮增强的是受范围约束的目录推理、原页补读与有预算的再搜索，不是更换底层索引算法。
- 本轮没有重跑全站31页、全部移动端或完整E2E矩阵；大型教师用书PDF的首次加载性能仍需继续验证。

## 提交前硬性自查

以下内容不是通知公布的评分项，而是依据通知要求设置的提交前门槛：

- [ ] 代码、文档、截图、录屏中无 API 密钥、Cookie、内部地址和个人路径；
- [ ] 每份第三方数据和工具有来源、用途、版本、许可证/授权说明；
- [ ] 课程标准、教材、教参的版本和页码可追溯；
- [ ] 所有 AI 生成材料标记为“AI初稿/待审核”；
- [ ] 不将系统推断标成课程标准或教材原文；
- [ ] 高风险数字与原始页面一致；
- [ ] 演示材料不含学生个人信息和保密内容；
- [ ] 所属单位确认项目符合“未以完成项目申报”的要求；
- [ ] 申报团队和职务成果归属完成内部确认；
- [ ] 2026年9月30日前完成正式提交并保存回执。

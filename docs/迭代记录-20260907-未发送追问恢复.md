# 未发送追问恢复

本轮回到教师主流程，不新增独立入口。

## 修复

- 未发送追问使用独立composerText字段保存在浏览器账号隔离的恢复缓存中，不再因已有回答而清空。
- 指定草稿时先读该草稿的本地输入；即使最近查看过别的草稿，也能从有限的最近记录中找回，不能串入其他草稿或账号。
- 同一草稿链接携带教材参数时同样允许恢复输入；明确新课或带q的动作仍遵循原隔离规则。
- 已清空或已发送后的空输入会保存，旧文字不会在刷新后复活。
- 旧缓存没有新字段时继续按旧规则处理，避免把上次已发送的问题当成待发送追问。
- 导出备课记录标题使用与页面相同的已确认篇目身份。

## 边界

未发送内容是本机恢复缓存（最多8条最近会话，7天有效期），不是跨设备云草稿。已发送对话仍以账号所属服务端草稿为真源。恢复输入不会自动调用模型。

## 验证

666项单元/接口测试通过；check/build通过。浏览器验证覆盖登录恢复、跨账号隔离、未发送输入刷新恢复/清空、明确草稿不得继承其他新课输入、连续问答到三卡和课堂主流程。带教材参数的同草稿恢复追加专项回归。测试使用本地隔离夹具，不调用付费模型。

# 活教参部署与公网验收手册

更新：2026-08-31

## 1. 生产拓扑

```text
教师浏览器
  → https://app.huojiaocan.workers.dev
  → Cloudflare Worker 固定入口
  → Vercel 项目 live-teacher-guide
      ├─ React/Vite 页面
      └─ Serverless BFF API
          ├─ Supabase Auth / Postgres / Storage
          ├─ 自部署 PageIndex
          ├─ 系统 OpenAI 兼容模型网关
          └─ DeepSeek 官方接口（仅用户选择个人连接时）
```

固定公网入口用于演示和验收；Vercel deployment URL 只用于发布排障，不应出现在教师端链接中。

## 2. 发布前门槛

在仓库 `demo/` 目录执行：

```bash
npm ci
npm test
npm run check
npm run build
```

通过标准：

- 测试无失败；
- 前端引用守卫无未解析符号；
- Vite 生产构建完成；
- Git 工作区只包含本次计划提交的文件；
- 不把本地 `.env`、账号、令牌、密钥、教材原文或测试日志加入提交。

## 3. 服务端环境变量

### 账号与存储

```text
SUPABASE_URL
SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY
SUPABASE_STORAGE_BUCKET
SUPABASE_STORAGE_PUBLIC_BASE_URL       # 可选
USER_DEEPSEEK_KEY_ENCRYPTION_SECRET
INDEX_MAINTAINER_EMAILS
```

### 系统模型

```text
LLM_GATEWAY_BASE_URL
LLM_GATEWAY_API_KEY
LLM_GATEWAY_MODEL                      # 或 LLM_TEXT_MODEL
LLM_GATEWAY_TIMEOUT_MS                 # 可选
AI_WORKFLOW_TIMEOUT_MS                 # 可选
```

### 教材索引

```text
DOCUMENT_INDEX_PROVIDER=pageindex
PAGEINDEX_BASE_URL
PAGEINDEX_API_KEY
PAGEINDEX_API_PREFIX                   # 按自部署服务实际前缀配置
PAGEINDEX_TIMEOUT_MS                   # 可选
ALLOW_INDEX_PROVIDER_FALLBACK=false    # 生产默认失败关闭
```

生产配置只能写入 Vercel 服务端环境变量。`SUPABASE_SERVICE_ROLE_KEY`、模型密钥、PageIndex 密钥和用户密钥加密主密钥不得进入 `VITE_*`、源码、日志、URL 或浏览器响应。

## 5. 公网自动验收

公开 PageIndex 链路：

```bash
cd demo
SITE_URL=https://app.huojiaocan.workers.dev npm run verify:production
```

脚本检查：

- 生产选择的是自部署 PageIndex，且没有静默切换 Provider；
- PageIndex vendor commit 与仓库固定版本一致；
- “沁园春·雪”跨学生教材/教师用书搜索能返回结果；
- 每条结果都有有效物理页，阅读器页码与结果页一致。

需要验证受保护的真实问答时，只在当前 shell 临时加入短时 access token：

```bash
PRODUCTION_AUTH_TOKEN='短时令牌' \
SITE_URL=https://app.huojiaocan.workers.dev \
npm run verify:production
```

不要把邮箱密码写进脚本或 CI。

## 6. 浏览器全链路验收

使用真实浏览器至少走一次：

```text
打开教材库
→ 选择篇目
→ 切换学生教材/教师用书并确认页码
→ 搜索并点击跨教材结果
→ 进入备课问答
→ 连续追问一轮
→ 教师确认方案
→ 生成一课三卡
→ 编辑并锁定一张卡
→ 刷新恢复
→ 打开板书课堂模式
→ 从引用返回准确教材页
```

同时检查：

- 桌面和窄屏无横向溢出；
- 浏览器控制台无运行时错误；
- 网络失败显示教师可理解的恢复动作；
- 跨教材目录加载失败时留在原页，不猜测目标页；
- 所有问答、三卡和教材核验入口保留 `draftId` 与返回路径；
- 页面不显示内部错误码、PageIndex、BFF 或模型网关名称。

## 7. 发布后确认

1. 对比页面加载的静态 bundle 是否来自新 deployment。
2. 检查 `/api/index/health` 和 `/api/index/retrieve`。
3. 使用一个受控测试账号完成问答和三卡链路，不复用个人长期密码。
4. 确认生产日志没有请求正文、Authorization、用户密钥或上游响应原文。
5. 将 deployment ID、Git commit、自动测试数和人工回归结论写入当次交付记录。

回滚时优先恢复上一条已验证 Vercel deployment；Cloudflare 固定入口保持不变。

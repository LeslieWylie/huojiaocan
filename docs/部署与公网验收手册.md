# “活教参”Demo V1.1 部署与公网验收手册

本文记录 2026 年 8 月 6 日完成的 V1.1 生产部署、配置边界和 ego lite 公网回归结果。当前交付是**可交互原型**，不是生产就绪系统。

## 1. 部署架构

```text
教师浏览器
    │ HTTPS
    ▼
Cloudflare Worker
（短网址、安全响应头、API 禁止缓存）
    │ HTTPS，固定上游
    ▼
Vercel
（React 页面 + Serverless API）
    │
    └─ fixture 证据样例；真实模型网关未启用
```

| 层级 | 地址或标识 | 用途 |
|---|---|---|
| 公网入口 | `https://app.huojiaocan.workers.dev` | 演示、答辩与公网验收 |
| Vercel 固定源站 | `https://live-teacher-guide.vercel.app` | Worker 的固定 HTTPS 上游 |
| Vercel 项目 | `live-teacher-guide` | 前端与 Serverless API |
| Cloudflare Worker | `app` | 反向代理和安全策略 |

V1.1 已重新部署，Vercel 固定别名已指向最新生产实例。公网短网址不含个人名称标识。

## 3. 数据和密钥边界

- 当前生产为 `fixture` 模式，核心演示不依赖外部模型；
- 原始教材、教师教学用书和比赛通知 PDF 不进入公网源码包；
- 浏览器端不保存网关地址、模型名称或密钥；
- `/api/config` 只返回布尔状态与运行模式；
- 曾在聊天中出现过的密钥视为已暴露，正式接入前必须轮换；
- 新密钥只能写入 Vercel 服务端环境变量，不能写入前端、Worker、源码、文档或截图。

服务端环境变量约定：

```text
LLM_GATEWAY_BASE_URL
LLM_GATEWAY_API_KEY
LLM_TEXT_MODEL
LLM_IMAGE_MODEL       # 可选
LLM_IMAGE_ENDPOINT    # 可选
```

## 4. 构建与发布

```bash
cd demo
npm ci
npm run check
npm run build
vercel --prod
```

发布后确认固定别名仍指向最新生产实例：

```bash
vercel alias set <deployment-host> live-teacher-guide.vercel.app
```

Cloudflare Worker 固定代理该别名，正常情况下无需随每次前端发布修改。

## 5. 公网 API 验收

使用公网入口：

```bash
BASE_URL='https://app.huojiaocan.workers.dev'

curl -fsS "$BASE_URL/api/health"
curl -fsS "$BASE_URL/api/config"
curl -fsS -X POST "$BASE_URL/api/ask" \
  -H 'Content-Type: application/json' \
  --data '{"question":"验证 PageIndex 证据问答"}'
```

2026 年 8 月 6 日实测：

- `/api/health`：`200`，`mode=fixture`；
- `/api/config`：`200`，三个模型配置状态均为 `false`；
- `/api/ask`：`200`，返回问题、结论、证据、45 分钟流程和卡片数据；
- 响应未暴露密钥、网关地址或模型名；
- 图片模型未配置时，前端展示内置演示画面，仍可完成路演。

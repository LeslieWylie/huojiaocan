# 备课工作台迭代 · 2026-09-11

状态：2026-09-11 已发布新版前端/API 与持久 Agent Worker；已补齐课件素材表和私有存储。没有创建 PR。下方保留本地证据，并追加线上验收结果。

## 本轮变化

- **重新生成与定稿**：提交前重新读取账号方案版本，并保留其他页面已保存的对话、依据夹和锁定卡片。生成未保存时不把旧的定稿入口标成新结果。后台已保存但回读失败时，明确提示重新打开，而不是要求再生成。
- **持久任务恢复**：复用已有 OpenMAIC Agent Session 实现。任务标识按账号与草稿保存在浏览器中；短暂断线退避重连，只读取本次请求；默认观察窗口为五分钟，单次状态读取最多二十秒。超出观察窗口不删除后台任务。保存重试不再调用模型，保存回执避免“写入成功、响应丢失”后的重复写入。依据不足不覆盖原方案。
- **侧栏入口**：本课工具携带草稿上下文；未选课程时先选择已有方案。同课异构提供两份同篇目、已确认课堂记录的选择入口。页面校正与质量检查可切换材料。导入页支持拖放与返回重新选文件。
- **教材原页**：教材库使用 PDF.js 直接绘制原始 PDF 指定物理页，避免浏览器内置 PDF 插件黑屏；保留原始 PDF 打开入口，以及失败重试。不是用解析文本或 AI 内容替代原页。
- **引导与进度**：一分钟真实本地页面演示，六个可跳转章节、中文合成旁白和字幕；示例方案明确标注。三卡生成不再用定时器假装完成各处理阶段，改为等待时长及明确标注的流程说明。

## 已观察到的结果

- 侧栏页面在桌面和手机宽度下可打开，课程选择及本课跳转可用；没有观察到页面脚本崩溃或横向溢出。
- 本地真实读写 API：问答页保留旧版本、另一页先保存、切换教学方式再生成，新版本成功保存并进入定稿页，另一页的补充对话没有丢失。此路径的模型返回为模拟内容。
- 浏览器故障注入：临时服务不可用后恢复原任务；保存冲突显示未写入的预览；这两条恢复路径没有另发生成请求。
- 保存接口模拟响应丢失：写入后重试复用原回执，没有再次写入；锁定卡片保留。持久任务的依据不足路径未调用保存。
- 原始教材第 56→57 页翻页、手机端加载失败后的重试已观察；视频可播放且第六章跳转正确。
- 前端构建与本次受影响的调用/按钮契约检查通过。构建仍有既有的大分块提示。

## 线上补充与根因

- 已确认旧线上《乡愁》任务有成功保存记录，不能将所有表现都归因于模型失败。

- 持久任务 Hyperdrive 原配置开启了查询缓存，实测数据库已保存而页面仍显示 composing。已禁用这一连接的 SQL 查询缓存，保留连接池和账号白名单。
- 恢复成功后清除旧的单页中断标记，避免已保存又提示“无法接回”。
- 素材表迁移与私有桶已创建；存储桶配置已加入生产环境。课件素材 API 合入既有 assets 函数，避免超过当前 Vercel 套餐的 12 个函数上限，公开 URL 不变。
- 线上视频时长 60 秒，第六章点击后从 50 秒实际播放；教材第 56 页的原始 PDF canvas 已绘制完成。
- 使用《乡愁》的独立验收副本，不修改原方案。真实模型从“讲授”调整成“小组合作”，后台完成保存；刷新后恢复原结果，定稿页读到小组合作条件。该任务 model_call_count=1，恢复没有新增生成调用。随后实际确认本版并生成三卡，服务器回读副本为小组合作、confirmed、三张卡；原方案仍为原版本和讲授条件。

# 智能体问答呈现整改

## 本轮交付
- 等待区显示当前篇目、实际等待秒数；45秒后提醒不要重复发送。不虚构实时阶段或百分比。
- 回答后的协作记录从服务端 agentRun.events 映射：教材依据、回答整理、课堂核对、教师确认。
- 缺少事件时不推断已完成；不直接显示服务端自由文本或内部错误。
- 处理记录和资料定位默认折叠，减少与正文争抢注意力。
- 删除无服务记录时自动展示的默认查阅步骤。
- 保留绿色纸张风格；390px下纵向排布，图标与文字共同表示状态。

## 验证
- 单测695项通过；新增缺失事件、无效事件、教师确认边界测试。
- npm run check通过（包含静态检查与构建）。
- 登录交接和保存恢复浏览器套件13项通过，其中新增390px等待、折叠展开、无横向溢出用例。
- 实际查看了窄屏协作记录截图。

## 边界

未改变调用编排、付费连接或草稿保存策略。
尚未部署；本开发分支的真实模型对照和生产隔离验证门禁仍需完成。

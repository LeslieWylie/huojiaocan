### 过程中发现并修复（提交 b9a1089、ce8e307）
1. **ask 提问按钮必现失效（生产级 bug）**：`ask-page.jsx` 中 `stableCoreQuestion` 同函数两次
   const 声明（第 524 解构 + 第 583 再声明），打包后第 546 行读取未初始化的后绑定 →
   `Cannot access 'ue' before initialization` → 点击提问根本不发请求，只显示“本次请求没有完成”。
2. **视图拆分丢失 import 一批**：`citationByRef`（ask→library-page）、`draftRecoverySnapshot`
   （ask→shell-pages）、`readOwnedDraftRecovery`（shell-pages→teacher-finalization）、
   rehearsal 恢复三函数（lesson-pages→cards-page）、`lessonStudyRecoveryKey`/`STUDY_DECISIONS`
   （lesson3→lesson2-pages）、`searchResultDocumentId/searchResultPage`（library-page→app-core）、
   `rootRequest`（ui-board）、`saveAuthRecovery/writeDraftRecovery/normalizeClassroomRun`
   （app-core）、图标 `Activity`（ask-page）与 `BookOpen/Eye/FileCheck2/Route`（inspect-pages）、
   `CARD_GENERATION_STEPS/CARD_SUBTITLES`（cards-page）、`normalizeLessonIdentity` 别名误用（g5-pages）。
3. **新增静态守卫 `demo/scripts/check-frontend-refs.mjs`**：扫描 src 下所有未解析的调用/JSX 组件/
   `icon={X}`/大写常量成员访问；已接入 `npm run check`。本次修复前它报出 12 处真问题。
4. **OCR 替换字符误判**：`drafts.js` 的 `citationComparableText` 归一化补充剥离 `U+FFFD`，

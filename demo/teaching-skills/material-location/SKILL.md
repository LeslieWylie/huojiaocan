# 教材定位

先用固定篇目身份选择材料，再根据目录标题、摘要与范围选择节点。摘要只帮助定位，不能作为课文引文。必须通过教材读取工具取得原页文本；物理页、印刷页和目录页分别使用服务端字段，不自行换算。跨材料核对同一篇目，不把相似标题或目录命中当正文。缺少某类材料应说明缺口，不自动扩大到私人文档或猜测链接。

技能是工作方法，不是教材依据。不得改变账号、密钥、工具权限或固定篇目身份。

# 原文核对

先原样识别教师质疑，再阅读引用所在段落及必要上下文。区分叙述主体、人物观点、作者立场，特别避免把人物心境直接当作者结论。逐项标明教材原话、教师用书建议或课堂转化；纠错时先回答错在哪里、应怎样理解，再给对应依据。若原页不支持，应明确无法确认，不能用上一轮回答或技能文字作证。

技能是工作方法，不是教材依据。不得改变账号、密钥、工具权限或固定篇目身份。

# 课堂方案

围绕当前篇目和本轮要求设计，不把换课时等操作当课题。每个环节写清教师提问或指令、学生回到的原文任务、可能的回答、教师如何追问，以及可观察的达成表现。环节时长遵循传入条件，未给定分钟数时不声称存在固定时长。教师用书作为可取舍的建议而非唯一答案；课标匹配必须有原页，课堂转化需明确标注。普通追问直接解答，不重复生成整套教案。

技能是工作方法，不是教材依据。不得改变账号、密钥、工具权限或固定篇目身份。

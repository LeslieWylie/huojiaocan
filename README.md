# 活教参

活教参是一套面向初中语文教师的循证备课与课堂工作台。它把课程标准、学生教材和教师教学用书放在同一条可核验链路中，支持教师从篇目定位开始，连续追问、确认方案、生成一课三卡，并把课堂记录接续到复盘与下一课。

生产入口：<https://app.huojiaocan.workers.dev/>

## 核心流程

```text
选择篇目
  → 核对学生教材与教师教学用书
  → 围绕当前篇目连续追问
  → 教师确认备课方案
  → 生成并编辑板书卡、提问卡、评价卡
  → 保存、锁定、投影或导出
  → 记录课堂事实并进入课后复盘
```

关键原则：

- **教材为主**：模型只能组织服务端提供的教材依据，不能自行生成页码、文档身份或核验链接。
- **篇目身份稳定**：追问“换成两课时”等调整指令只改变教学安排，不改写篇目和板书课题。
- **教师最终确认**：AI 初稿可继续追问和编辑；只有教师确认后才能生成正式三卡。
- **结果可接续**：草稿、版本、锁定卡片、课堂记录和班级接续均以账号数据为准。

## 当前能力

- 三源材料：课程标准、学生教材、教师教学用书。
- 教材目录、跨教材搜索、物理页定位和原页核验。
- 带历史上下文的连续备课问答与有限轮次的检索—审校工作流。
- 方案定稿、版本恢复、一课三卡、渐进式板书、课堂投影与导出。
- 教研资产、同课异构、听评课、问题链预演、课前摸底、分层作业和课后复盘。
- Supabase 邮箱密码登录、账号隔离和个人 DeepSeek 连接管理。

## 技术结构

```text
React/Vite 教师端
  └─ 同源 BFF API
      ├─ Supabase Auth / Postgres / Storage
      ├─ 自部署 PageIndex 教材索引
      ├─ 系统 OpenAI 兼容模型网关
      └─ 用户个人 DeepSeek 官方接口（可选）
```

目录说明：

- `demo/`：教师端、BFF、领域模块和测试。
- `services/pageindex-service/`：自部署 PageIndex 适配服务。
- `supabase/`：数据表、RLS 与迁移。
- `deployment/`：Cloudflare Worker 等部署配置。
- `docs/`：架构、交付、验收和比赛材料。

代码结构图见 [`docs/代码架构图.generated.md`](docs/代码架构图.generated.md)。它由实际页面路由、Vite 构建入口和服务端路由生成；提交检查会阻止过期架构图进入主分支。

## 本地开发

```bash
cd demo
npm install
npm run dev
```

默认页面为 `http://127.0.0.1:5173`，本地 API 由同一命令启动。提交前执行：

```bash
npm test
npm run check
npm run build
```

全链路本地演练可使用仓库内的确定性 mock：

```bash
cd demo
MOCK_PORT=54321 node scripts/mock-supabase.mjs
```

详细环境变量、第二个 mock 网关进程和生产验收步骤见 [`demo/README.md`](demo/README.md) 与 [`docs/部署与公网验收手册.md`](docs/部署与公网验收手册.md)。

## 协作约定

- 页面逻辑放在 `demo/src/views/`；`App.jsx` 只保留路由装配。
- 共享领域逻辑优先放入 `demo/shared/`，不要把服务端规则复制到组件中。
- 教师端不展示内部服务名、错误码和部署细节；开发者文档可以保留技术名称。
- 新页面必须加入 `ROUTES`、Vite 构建入口和导航合同测试。
- 新按钮必须有明确动作和可读名称；新链接必须指向已声明页面。`npm run check` 会校验按钮、链接与路由合同。
- 教材定位必须同时保持文档、物理页、篇目、目录节点和返回地址一致。
- 不提交密钥、账号密码、服务端环境值、真实教材原文或本地运行产物。
